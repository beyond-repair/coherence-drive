## Minimal criterion for a new branch

A genuinely new propulsion branch begins with a document containing:

1. New law  
2. Independent motivation  
3. Mathematical consequences  
4. Observable prediction  
5. **No** reference to target thrust as a fit parameter  

Only after those are frozen does computation become meaningful.

Otherwise the workflow becomes target → parameter choice → simulation → target reproduced — **calibration, not prediction**.
